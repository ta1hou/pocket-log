Облачная память ☁

Сайт работает бесплатно на GitHub Pages. Для общей базы на телефоне и ноутбуке создай отдельный приватный репозиторий, например pocket-log-data. В нём появится один файл pocket-log-data.json.

Создай токен на GitHub → Fine-grained tokens. Ограничь доступ только репозиторием базы, разрешение Contents: Read and write. Никогда не добавляй токен в файлы сайта.

Срок действия токена (введи дату из настроек GitHub)

Срок можно посмотреть в списке токенов GitHub. Напомним за 30, 14 и 7 дней до указанной даты. Если GitHub передаст браузеру реальный срок, обновим его автоматически. Без даты предупреждение заранее невозможно.
